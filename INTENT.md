# 🎯 INTENT — `.github` (repositório da organização)

> **O que é:** o repositório **especial** da org (`github.com/fbso-techsolutions/.github`). O GitHub
> usa o conteúdo daqui como **default** para todos os repositórios. **Não** é um repositório de código.

## 1. Papel

Fornecer os defaults da organização para que todo repo nasça com o mesmo padrão: templates de
issue/PR, health files (`CONTRIBUTING.md`, `SECURITY.md`, `GOVERNANCE.md`) e starter workflows.

## 2. O que NÃO vive aqui

- **Reusable workflows / composite actions** → `platform-standards/.github/workflows/` (via `uses:`).
- **Regras de processo/engenharia/arquitetura/segurança** → `platform-standards/standards/`.
